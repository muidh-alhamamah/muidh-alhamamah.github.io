# Portfolio — معيض سالم آل حمامة

موقع ثابت ثنائي اللغة (AR/EN) بدون مكتبات أو أدوات بناء. يُستضاف مجانًا على GitHub Pages.

## التعديل
كل المحتوى في `assets/js/data.js`:
- مشروع جديد: انسخ كتلة داخل `PROJECTS` وملفات المشروع في `assets/projects/graduation/` ثم `files`.
- شهادة جديدة: انسخ كتلة داخل `CERTS` (`featured: true` لإبرازها، `link` لرابط التحقق).
- الخبرات/التعليم/المهارات/الأدوات: `EXPERIENCE` / `EDUCATION` / `SKILLS` / `TOOLS`.
- الروابط والجوال: `SITE` (الحقل الفارغ يُخفى تلقائيًا).

## السيرة الذاتية
استبدل الملفين في `assets/cv/` بنفس الاسمين:
`Muidh-Salem-CV-EN.pdf` و `Muidh-Salem-CV-AR.pdf`.

## روابط مفيدة
- `?lang=en` أو `?lang=ar` في آخر الرابط لفتح الموقع بلغة محددة.
